# tool-inventory-browser-web

Live demo: [https://kareembullard.github.io/tool-inventory-browser-web/](https://kareembullard.github.io/tool-inventory-browser-web/)

Filterable, sortable browser over a sample software tool inventory.

## What it is

A static, single-file web app version of [tool-inventory-browser](https://github.com/kareembullard/tool-inventory-browser) (the original tkinter + Airtable-backed desktop app). This public version:

- Ships with a **generic sample dataset** of 20 well-known, publicly-recognizable tools (VS Code, Figma, Notion, Slack, etc.) — the ratings and "stacked" flags are illustrative examples, not anyone's real personal opinions
- Has **no Airtable dependency** and makes no network calls
- Read-only, exactly like the original

Multi-select filters on Area/Function/Platform, free-text search, click-to-sort columns.

## Run locally

Just open `index.html` in a browser — no build step, no server required.
